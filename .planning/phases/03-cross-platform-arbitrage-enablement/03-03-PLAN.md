  <behavior>
Expected behavior for settlement comparison:

**Multi-level similarity scoring:**
- questionSimilarity: Dice coefficient of normalized question text (0-1)
- criteriaSimilarity: Dice coefficient of primary rule text (0-1)
- timingSimilarity: Date proximity score (0 days = 1.0, 14+ days = 0.0)
- dataSourceSimilarity: Dice coefficient of data source names (0-1)
- overallSimilarity: Weighted average (question 0.3, criteria 0.4, timing 0.2, source 0.1)

**Risk factor detection:**
- Missing resolution date -> "Missing resolution date"
- Dates differ >7 days -> "Resolution dates differ by N days"
- Data sources differ significantly -> "Different data sources"
- Subjective keywords detected -> "Subjective criteria detected: X"

**Safety determination (Phase 3.1 conservative thresholds):**
- overall >= 0.9 AND
- criteria >= 0.7 AND
- timing >= 0.5 AND
- no critical risk factors AND
- manual_override != 'unsafe'

**Test cases:**
- compare(identical markets) -> overall 1.0, safe = true
- compare(similar question, different criteria) -> overall < 0.9, safe = false
- compare(same event, 30-day timing gap) -> timing 0.0, safe = false
- compare(market with manual_override='unsafe') -> safe = false regardless of scores
- compare(market with manual_override='safe') -> safe = true regardless of scores
  </behavior>
