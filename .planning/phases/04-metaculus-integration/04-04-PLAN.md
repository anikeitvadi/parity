Expected behavior in testable terms:

**Divergence calculation:**
- Metaculus 0.65, Market 0.70 -> 5% divergence (flagged at threshold)
- Metaculus 0.65, Market 0.60 -> 5% divergence (flagged)
- Metaculus 0.65, Market 0.68 -> 3% divergence (not flagged)

**Staleness detection:**
- 3 days old -> isFresh: true, no warning
- 7 days old -> isFresh: true (edge of threshold), no warning
- 8 days old -> isFresh: false, warning: "Forecast is 7-14 days old..."
- 21 days old -> isFresh: false, warning: "Forecast is 2-4 weeks old..."
- 45 days old -> isFresh: false, warning: "Forecast is 45 days old - likely outdated"

**Feature flag:**
- metaculusDivergence: false -> return empty array immediately
- metaculusDivergence: true -> run detection

**Output format:**
- type: 'metaculus_divergence'
- All fields from MetaculusDivergenceOpportunity type
- Ready for aggregator normalization

Test cases:
1. Feature flag disabled -> empty array
2. No questions from API -> empty array
3. No matches found -> empty array
4. Match without community_prediction -> skip
5. 5% divergence with fresh forecast -> opportunity returned
6. 3% divergence -> not flagged
7. Stale forecast (>7 days) -> flagged with warning
8. Multiple matches -> returns all qualifying opportunities
  </behavior>

Class structure:
```typescript
export class MetaculusDivergenceDetector {
  private client: MetaculusClient;
  private matcher: MetaculusMatcher;
  private minDivergence: number;  // Default 5
  private readonly STALE_THRESHOLD_DAYS = 7;

  constructor(token?: string, minDivergence?: number, matcherConfidence?: number)

  async detect(markets: Market[]): Promise<MetaculusDivergenceOpportunity[]>

  private checkStaleness(forecastTimestamp: string): ForecastStaleness

  private calculateDivergence(
    metaculusPrediction: number,
    marketPrice: number
  ): { divergencePercent: number; hasDivergence: boolean }

  private extractMarketPrice(market: Market): number | null
}
```

Key implementation:
1. Check feature flag FIRST (return [] if disabled)
2. Fetch questions via client (binary, open, limit 100)
3. Match questions to markets via matcher
4. For each match:
   - Skip if no community_prediction
   - Extract market price (Yes outcome)
   - Calculate divergence
   - If divergence >= minDivergence:
     - Check staleness
     - Build MetaculusDivergenceOpportunity
     - Push to results
5. Log stats (questions checked, matches found, divergences detected)
6. Return sorted by divergencePercent descending

Use logger.child({ component: 'metaculus-divergence' })
