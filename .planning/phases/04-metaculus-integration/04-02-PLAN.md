  <action>
Create MetaculusClient following existing client patterns (kalshi.ts, polymarket.ts).

Class structure:
```typescript
export interface MetaculusSearchParams {
  limit?: number;        // Default: 100
  offset?: number;       // Default: 0
  status?: 'open' | 'closed' | 'resolved';  // Default: 'open'
  forecast_type?: 'binary' | 'numeric';
  order_by?: string;     // Default: '-created_time'
}

export class MetaculusClient {
  private client: AxiosInstance;
  private token: string;

  constructor(token?: string)
  async searchQuestions(params?: MetaculusSearchParams): Promise<MetaculusQuestion[]>
  async getQuestion(id: number): Promise<MetaculusQuestion>
  async getQuestionByUrl(url: string): Promise<MetaculusQuestion>
}
```

Implementation details:
1. Constructor:
   - Accept token parameter, fall back to process.env.METACULUS_TOKEN
   - Throw if no token available (with clear error message)
   - Create axios instance with baseURL 'https://www.metaculus.com/api'
   - Set timeout: 30000 (30 seconds)
   - Set headers: Authorization: `Token ${token}`, Content-Type: application/json

2. Configure axios-retry:
   - retries: 5
   - retryDelay: axiosRetry.exponentialDelay (built-in exponential with jitter)
   - retryCondition: retry on network errors, idempotent request errors, AND 429 status
   - onRetry: log warning with retryCount, status, url using logger

3. searchQuestions():
   - GET /questions/ with params
   - Validate response with MetaculusQuestionSchema (array)
   - Return response.data.results or empty array
   - Log info on success with question count

4. getQuestion():
   - GET /questions/{id}/
   - Validate response with MetaculusQuestionSchema
   - Return response.data

5. getQuestionByUrl():
   - Extract ID from URL pattern /questions/(\d+)/
   - Call getQuestion() with extracted ID
   - Throw descriptive error if URL invalid

Error handling:
- Catch errors, log with context (questionId, params, error)
- Re-throw for caller to handle

Use child logger: logger.child({ component: 'metaculus-client' })
