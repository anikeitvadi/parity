Expected behavior in testable terms:

**Title similarity:**
- "Will Trump win the 2024 election?" vs "Will Trump win 2024 election" -> 0.95+
- "Will Trump win Michigan?" vs "Will Trump win?" -> < 0.7 (different scope)
- Normalize: lowercase, remove punctuation, collapse whitespace

**Timing similarity (linear decay over 14 days):**
- 0 days difference -> 1.0
- 7 days difference -> 0.5
- 14+ days difference -> 0.0

**Overall confidence (weighted):**
- title: 50%, description: 30%, timing: 20%
- Minimum 0.8 overall confidence for match
- Manual matches always 1.0 confidence

**Manual override:**
- If metaculus_id exists in metaculus-matches.json with verified: true, use that match
- Skip algorithmic matching for manually curated pairs

Test cases:
1. Exact title match -> confidence ~1.0
2. Similar title, same resolution date -> confidence 0.85+
3. Similar title, 30 days apart -> confidence < 0.8 (rejected)
4. Manual match overrides algorithmic match
5. Binary questions only (filter out numeric/date)
6. Empty inputs return empty matches
  </behavior>

Class structure:
```typescript
export interface MetaculusMatchResult {
  metaculusQuestion: MetaculusQuestion;
  market: Market;
  confidence: number;
  similarity: {
    title: number;
    description: number;
    timing: number;
    overall: number;
  };
  method: 'exact_match' | 'high_similarity' | 'manual_curated';
}

export class MetaculusMatcher {
  constructor(manualMatchesPath?: string, minConfidence?: number)
  matchToMarkets(questions: MetaculusQuestion[], markets: Market[]): MetaculusMatchResult[]
  private calculateSimilarity(question, market): SimilarityScores
  private normalizeText(text: string): string
  private compareTimings(date1: Date, date2: Date): number
  private findManualMatch(metaculusId: number): ManualMatch | undefined
  private loadManualMatches(path: string): void
}
```

Key implementation details:
1. Use string-similarity.compareTwoStrings for title/description
2. Filter to binary questions only (q.type === 'binary')
3. Load manual matches from JSON file (same pattern as MarketMatcher)
4. Conservative 0.8 threshold (vs 0.7 for cross-platform per research)
5. Log low-confidence matches for manual review (debug level)
