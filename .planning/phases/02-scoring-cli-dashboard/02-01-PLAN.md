  <behavior>
Score opportunities on 1-10 scale using weighted factors:

**Factor weights (default, configurable):**
- Edge size: 35% (RATE-02)
- Confidence: 25% (RATE-03)
- Liquidity: 20% (RATE-04)
- Time to resolution: 10% (RATE-05)
- Fee-adjusted profit: 10% (RATE-06)

**Edge size factor (0-10):**
- <5% net edge: 1-2 (below threshold)
- 5-7% net edge: 3-4 (marginal)
- 7-10% net edge: 5-6 (decent)
- 10-15% net edge: 7-8 (good)
- 15-20% net edge: 9 (excellent)
- >20% net edge: 10 (exceptional)

**Confidence factor (0-10):**
- Detector confidence (0-1) × 10
- For cross-platform: (detector × match confidence) × 10

**Liquidity factor (0-10):**
- <$500: 0 (below minimum)
- $500-1000: 3
- $1000-5000: 5
- $5000-10000: 7
- $10000-50000: 9
- >$50000: 10

**Time to resolution factor (0-10):**
- <1 day: 10 (urgent)
- 1-3 days: 8
- 3-7 days: 6
- 7-30 days: 4
- >30 days: 2 (long-term)
- No date: 5 (neutral)

**Fee-adjusted profit factor (0-10):**
- Based on net edge after platform fees
- Apply $0.05 minimum threshold (skip if below)
- Score: min(netEdge × 100, 10)

**Minimum threshold (RATE-06):**
- $0.05 net profit on $100 trade = 5% net edge
- Opportunities below threshold not scored (return null)

Test cases:
- 12% edge, 0.9 confidence, $5K liquidity, 3 days: ~7.5 score
- 6% edge, 0.8 confidence, $2K liquidity, 14 days: ~4.5 score
- 3% edge (below threshold): returns null
- Custom weights: verify weighted average calculation
- Edge cases: zero confidence, max liquidity, missing close date
  </behavior>

```typescript
interface UnifiedOpportunity {
  id: string;
  type: 'multi_outcome' | 'correlated' | 'cross_platform';
  platform: 'polymarket' | 'kalshi' | 'cross';
  marketId: string;
  marketQuestion: string;
  grossEdge: number;      // 0-1 scale
  netEdge: number;        // 0-1 scale, after fees
  detectorConfidence: number;  // 0-1
  matchConfidence?: number;    // 0-1, for cross-platform
  minLiquidity: number;        // USD
  liquidityDepth: number;
  detectedAt: number;          // Unix ms
  closeDate?: string;          // ISO date
  raw: unknown;                // Original detector output
}

interface ScoredOpportunity extends UnifiedOpportunity {
  score: number;                // 1-10
  scoreBreakdown: ScoreBreakdown;
  positionSize: number;         // USD (from Kelly, added in plan 02-02)
  positionPercent: number;      // % of bankroll
}

interface ScoreBreakdown {
  edgeScore: number;
  confidenceScore: number;
  liquidityScore: number;
  timeScore: number;
  profitScore: number;
  weights: ScoringWeights;
}

interface ScoringWeights {
  edgeSize: number;
  confidence: number;
  liquidity: number;
  timeToResolution: number;
  feeAdjustedProfit: number;
}
```
