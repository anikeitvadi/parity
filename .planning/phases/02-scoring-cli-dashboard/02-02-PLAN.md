  <behavior>
Calculate position size using Kelly criterion with safety adjustments:

**Formula:**
- Full Kelly: f* = edge × confidence
- Half-Kelly (default): f = f* × 0.5
- Cap at 10% of bankroll

**Inputs (SIZE-02):**
- edge: Estimated edge (0-1), e.g., 0.10 = 10%
- confidence: Confidence in edge estimate (0-1)
- bankroll: Total capital in USD

**Outputs:**
- positionSize: Suggested size in USD
- positionPercent: Position as % of bankroll
- cappedBy: What limited the position ('none' | 'kelly' | 'max')

**Examples with $500 bankroll:**
- 10% edge, 0.9 confidence → 0.10 × 0.9 × 0.5 = 4.5% → $22.50
- 20% edge, 0.8 confidence → 0.20 × 0.8 × 0.5 = 8% → $40.00
- 30% edge, 0.9 confidence → 0.30 × 0.9 × 0.5 = 13.5% → capped to 10% → $50.00

**Edge cases:**
- Zero edge: return $0
- Negative edge: return $0
- Very low confidence (<0.1): return $0
- Very high edge (>50%): still cap at 10%

Test cases:
- Standard: 10% edge, 0.8 confidence, $500 bankroll → $20 (4%)
- High edge: 25% edge, 0.9 confidence, $500 bankroll → $50 (10%, capped)
- Low edge: 3% edge, 0.5 confidence, $500 bankroll → $3.75 (0.75%)
- Zero edge: returns { positionSize: 0, cappedBy: 'kelly' }
- Configurable fraction: fraction=0.25 (quarter-Kelly)
- Configurable cap: maxPosition=0.05 (5% cap)

```typescript
interface KellyInput {
  edge: number;           // 0-1 scale
  confidence: number;     // 0-1 scale
  bankroll: number;       // USD
  fraction?: number;      // Default 0.5 (half-Kelly)
  maxPosition?: number;   // Default 0.10 (10% cap)
}

interface KellyOutput {
  positionSize: number;      // USD, rounded to cents
  positionPercent: number;   // 0-100 scale
  cappedBy: 'none' | 'kelly' | 'max';
}

function calculateKelly(input: KellyInput): KellyOutput {
  const { edge, confidence, bankroll, fraction = 0.5, maxPosition = 0.10 } = input;

  // Handle edge cases
  if (edge <= 0 || confidence < 0.1) {
    return { positionSize: 0, positionPercent: 0, cappedBy: 'kelly' };
  }

  // Kelly calculation
  const adjustedEdge = edge * confidence;
  const fullKelly = adjustedEdge;
  const fractionalKelly = fullKelly * fraction;

  // Apply cap
  const finalFraction = Math.min(fractionalKelly, maxPosition);
  const cappedBy = finalFraction < fractionalKelly ? 'max' : 'none';

  return {
    positionSize: Math.round(bankroll * finalFraction * 100) / 100,
    positionPercent: finalFraction * 100,
    cappedBy,
  };
}
```
