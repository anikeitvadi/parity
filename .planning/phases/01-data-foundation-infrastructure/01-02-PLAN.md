  <behavior>
Database must store market snapshots from multiple platforms with:

Schema (from 01-RESEARCH.md lines 209-224):
- market_snapshots table: id, platform, market_id, timestamp, data (JSON)
- UNIQUE constraint on (platform, market_id, timestamp)
- Indexes on (platform, timestamp DESC) and (market_id, timestamp DESC)

Insert behavior:
- insertSnapshot(platform, marketId, timestamp, data) → ignores duplicates
- insertMany(snapshots[]) → batches in transaction for 10-100x speedup

Query behavior:
- getRecentSnapshots(platform, limit) → returns N most recent snapshots
- getMarketHistory(marketId, startTime, endTime) → returns time range
- getLatestSnapshot(platform, marketId) → returns most recent for that market

Test cases:
- Insert snapshot → can retrieve it
- Insert duplicate → ignores (INSERT OR IGNORE)
- Batch insert 100 snapshots in <100ms (transaction speedup)
- Query by platform returns only that platform's data
- Query by time range filters correctly
- Concurrent reads during writes (WAL mode verification)
