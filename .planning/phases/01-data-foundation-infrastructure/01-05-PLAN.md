<feature>
  <name>Cross-Platform Market Matcher</name>
  <files>src/services/market-matcher.ts, tests/market-matcher.test.ts</files>
  <behavior>
Market matcher must identify equivalent events across Polymarket and Kalshi:

Matching algorithm (Phase 1 - exact text + curation):
1. Normalize text: lowercase, remove special chars, trim whitespace
2. Extract keywords: Remove common words (the, a, will, etc.)
3. Exact match on normalized keywords
4. Manual curation file: src/data/manual-matches.json
   - Format: [{ polymarket_id, kalshi_ticker, verified: true }]
   - Overrides algorithmic matches

Input: Market[] from Polymarket, Market[] from Kalshi
Output: MatchedPair[] with { polymarket, kalshi, confidence, method }

Confidence scoring:
- exact_match: 1.0 (normalized text identical)
- manual_curated: 1.0 (from manual-matches.json)
- keyword_match: 0.7-0.9 (based on keyword overlap %)
- no_match: 0.0

Filters:
- Minimum confidence: 0.7
- Same resolution timeframe (within 7 days)
- Same number of outcomes (binary vs binary, multi vs multi)

Test cases:
- Exact match: "Will Trump win 2024?" (Poly) vs "Will Trump win 2024?" (Kalshi) → confidence 1.0
- Keyword match: "Trump 2024 win" vs "2024 Trump victory" → confidence 0.8+
- Different outcomes: Binary market vs 5-outcome market → no match
- Different timeframes: Resolves Jan 2024 vs Dec 2024 → no match
- Manual override: manual-matches.json entry overrides algorithm
- Edge case: Empty markets array → returns []
- Edge case: No matches found → returns []
  </behavior>
