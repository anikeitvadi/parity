  <action>
Create ecosystem.config.js for PM2:

```javascript
module.exports = {
  apps: [{
    name: 'market-scanner',
    script: './dist/index.js',
    instances: 1,
    autorestart: true,
    watch: false,
    max_memory_restart: '1G',
    env_production: {
      NODE_ENV: 'production'
    },
    error_file: './logs/err.log',
    out_file: './logs/out.log',
    log_date_format: 'YYYY-MM-DD HH:mm:ss Z',
    combine_logs: true,
    merge_logs: true
  }]
};
```

Create deploy.sh:
```bash
#!/bin/bash
set -e

echo "Deploying market scanner to VPS..."

# Build locally
npm run build

# Copy to VPS (replace with actual VPS IP)
VPS_IP="${VPS_IP:-your-vps-ip}"
rsync -avz --exclude node_modules --exclude .git . $VPS_IP:~/market-scanner/

# SSH and install
ssh $VPS_IP << 'EOF'
  cd ~/market-scanner
  npm install --production
  pm2 reload ecosystem.config.js --env production
  pm2 save
EOF

echo "Deployment complete"
```

Create .env.production template:
```
NODE_ENV=production
POLYMARKET_PRIVATE_KEY=your_hot_wallet_private_key_here
POLYMARKET_API_KEY=your_api_key_if_needed
KALSHI_API_KEY=your_kalshi_api_key
KALSHI_API_SECRET=your_kalshi_api_secret
```
