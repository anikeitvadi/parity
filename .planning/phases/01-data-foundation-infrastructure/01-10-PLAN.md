  <behavior>
Detect arbitrage opportunities across Polymarket and Kalshi for matched markets:

**CRITICAL SAFETY:** This detector is built in Phase 1 but DISABLED until Phase 3 settlement verification. Settlement divergence causes DOUBLE LOSSES (lose on both platforms).

Arbitrage patterns:

1. Price divergence arbitrage:
   - Polymarket: YES at 60%, Kalshi: YES at 45%
   - Buy Kalshi at 45%, sell Polymarket at 60%
   - Guaranteed profit IF settlement rules match: 15% edge

2. Inverse arbitrage:
   - Polymarket: YES at 40%, Kalshi: NO at 40% (implies YES=60%)
   - Buy Polymarket YES, sell Kalshi NO
   - Edge: 20%

Input: Matched market pairs from matched_markets table
Output: CrossPlatformOpportunity[] with { polymarket, kalshi, type, edgeSize, settlementRisk }

Edge size calculation:
- Price divergence: abs(poly_price - kalshi_price)
- Account for fees on BOTH platforms:
  - Polymarket: ~2% per trade
  - Kalshi: ~7% fee (3% maker, 7% taker)
  - Net edge = gross_edge - (poly_fee + kalshi_fee)
  - Minimum threshold: 10% (to cover fees + settlement risk)

Settlement risk scoring:
- HIGH risk: Different settlement mechanisms (UMA oracle vs centralized)
- MEDIUM risk: Different resolution timestamps
- LOW risk: Same data source, same rules
- Phase 1: ALL flagged as HIGH risk (no settlement parser yet)

Liquidity validation:
- Check order book depth on BOTH platforms
- Minimum $500 per side
- If either platform lacks liquidity, skip

Test cases:
- Poly 60% / Kalshi 45% with good liquidity: flag opportunity (15% gross edge, ~6% net after fees)
- Poly 55% / Kalshi 50% with good liquidity: skip (5% gross edge, negative net after fees)
- Poly 70% / Kalshi 40% but Kalshi only $200 depth: skip (liquidity filter)
- Poly 65% / Kalshi 50% but feature flag disabled: return empty array (DISABLED behavior)
- Matched markets with high confidence (>0.8): prioritize for detection
- Matched markets with low confidence (<0.5): skip (not reliable match)
- Edge case: Stale data (>30 min old) → skip
- Edge case: Market already resolved → skip
- Settlement risk always HIGH in Phase 1 (no parser yet)

Confidence scoring (for Phase 2 alert rating):
- 0.9-1.0: Large edge (>15% net) with deep liquidity
- 0.7-0.9: Moderate edge (10-15% net)
- <0.7: Skip (too risky given fees and settlement unknowns)

Feature flag behavior:
- If featureFlags.crossPlatformArb === false: return empty array, log warning
- Phase 1 default: DISABLED
- Phase 3 enables after settlement verification operational
