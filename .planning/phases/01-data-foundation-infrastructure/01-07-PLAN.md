<feature>
  <name>Correlated Markets Consistency Detector</name>
  <files>src/detectors/correlated-markets.ts, tests/correlated-markets.test.ts</files>
  <behavior>
Detect pricing inconsistencies in correlated markets on the same platform:

Detection patterns:

1. Binary market inconsistency:
   - YES price + NO price should equal ~100% (within 1-2% tolerance for fees)
   - If sum > 102% or < 98%, flag as mispricing opportunity
   - Example: YES=55%, NO=50% (sum=105%) → opportunity to sell both

2. Multi-outcome market inconsistency:
   - Sum of all outcome prices should equal ~100%
   - If sum > 102% or < 98%, flag arbitrage
   - Example: 3 outcomes at 40%, 35%, 30% (sum=105%) → sell all three

3. Complementary markets:
   - "Trump wins" vs "Trump loses" should be inverse
   - Check if both exist on same platform with incompatible prices

Input: Market[] with prices for each outcome
Output: CorrelatedOpportunity[] with { markets, type, edgeSize, expectedValue }

Edge size calculation:
- Binary: abs((yes + no) - 100)
- Multi-outcome: abs(sum(prices) - 100)
- Only flag if edge > 2% (accounts for fees + bid-ask spread)

Test cases:
- Binary market sum = 100%: no opportunity
- Binary market sum = 105%: flag opportunity (5% edge)
- Binary market sum = 95%: flag opportunity (5% edge, buy both)
- Multi-outcome 3 markets sum = 108%: flag opportunity
- Multi-outcome 5 markets sum = 100%: no opportunity
- Edge case: Market with missing price data → skip, log warning
- Edge case: Single outcome market → skip (no correlation check)
- Liquidity filter: Only flag if all outcomes have >$500 depth

Confidence scoring:
- 0.9-1.0: Clear inconsistency (>5% edge)
- 0.7-0.9: Moderate (2-5% edge)
- <0.7: Don't flag (within normal spread)
  </behavior>
